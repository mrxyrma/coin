## Как запустить

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 9 тестов на математику траектории
npm run build        # tsc + vite build
npx eslint .
```

Отладка траектории: **http://localhost:5173/?coin=debug** — DOM-кружок летит по той же
кривой, что и 3D-монета, с выводом координат, диаметра и угла.

## Ключевые файлы

| Файл | Зачем |
|---|---|
| `src/lib/trajectory.ts` | **Единственное место с цифрами анимации**: наклон, полуобороты, вынос дуги `bulgeOut` |
| `src/lib/coinPath.ts` | Обмер якорей и чистая функция `samplePath` — вся математика пути |
| `src/lib/pixelCamera.ts` | Камера, в которой 1 мировая единица = 1 CSS-пиксель |
| `src/lib/coinStore.ts` | Металл и сторона монеты; доворот от клика живёт вне React |
| `src/ui/CoinAnchor.tsx` | Невидимый якорь — позицию монеты задаёт CSS секции, не JS |

## Что делать дальше

1. **Запросить ассеты у дизайнера** — [designer-request.md](./designer-request.md),
   документ готов к пересылке как есть. Техническая версия того же — в
   [PLAN.md](./PLAN.md), раздел «ТЗ дизайнеру на ассеты». Модель монеты самая
   долгая по срокам, просить в первую очередь.
2. Когда приедут: этап 4 (модель, HDRI, DRACO+KTX2), затем этап 5 (футляры,
   сцена укладки в ложемент).
3. Не блокировано ассетами: тонкая подгонка выносок в «уникальности»,
   hover-реакция монеты на курсор, прогон вёрстки по ширинам 768/1024/1920.

## Открытые вопросы

- Текста реверса в макете нет — в `src/sections/Appearance.tsx` стоит заглушка.
- Логотип Сбера — лицензионный ассет, в `src/ui/SberLogo.tsx` серый плейсхолдер.
- Шрифты SB Sans есть у заказчика; до подключения работают фолбэки
  (блок `@font-face` заготовлен в `src/index.css`).
- Макет прототипный: при обновлении правятся CSS-позиции `.coin-anchor`
  и числа `bulgeOut` — код траектории не трогается.
